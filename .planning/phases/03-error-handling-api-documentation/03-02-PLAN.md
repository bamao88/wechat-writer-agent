**架构说明**: Agent SDK 通过 `query()` 函数内部调用 Skill,我们无法直接控制其子进程调用。
因此,集成方式是在 **AgentRunMetrics 和 hooks 层** 增强错误追踪,而非替换 SDK 内部实现。

1. **在 AgentRunMetrics 中添加 tool_failures 追踪**:
```python
@dataclass
class AgentRunMetrics:
    # ... 现有字段 ...
    tool_failures: List[Dict[str, Any]] = field(default_factory=list)

    def add_tool_failure(self, tool_name: str, tool_use_id: str, error: str, stderr: str = None):
        """记录工具调用失败"""
        self.tool_failures.append({
            "tool_name": tool_name,
            "tool_use_id": tool_use_id,
            "error": error,
            "stderr": stderr,
            "timestamp": time.time()
        })
```

2. **在 generate 方法的 hooks 配置中启用错误追踪**:
   - hooks 已通过 lambda 闭包注入 metrics 实例

   - 这样 agent_sdk.py 通过 metrics 收集工具失败信息
