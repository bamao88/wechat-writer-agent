   - This is the "early warning" threshold (default 10 seconds per ERR-02)
   - The hard timeout remains at 180 seconds (existing)

2. Implement timeout detection using time measurement:
   - Record start_time before subprocess.run

   - If subprocess exceeds hard_timeout, raise TimeoutError as before

4. Update the TimeoutError handling to use NotebookLMError:
   - error_type: "timeout_error"
   - Include attempted query in error message
