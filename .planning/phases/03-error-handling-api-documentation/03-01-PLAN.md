   - 返回结构化结果: `{success, stdout, stderr, returncode, error_message, timeout_occurred}`
   - 使用 `capture_output=True, text=True, errors='replace'` 处理编码问题

   - 支持传递环境变量和超时参数

   - `subprocess.CalledProcessError`: 非零退出码
   - `subprocess.TimeoutExpired`: 超时
   - `FileNotFoundError`: 命令不存在
   - 其他异常: 通用错误

   - 不使用 `check=True`,手动检查 returncode 以避免未捕获异常
   - stderr 完整记录(至少前 2000 字符)
   - 支持可选的 env 字典显式传递环境变量
