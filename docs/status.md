### 架构差异说明

| 规划 | 实际实现 | 差异原因 |
|------|---------|---------|
| Agent + 代码编排 | 模块化 Python | 更易测试和维护 |
| Agent 主动检索 | 预先检索 + Agent 可追加 | 兼顾结构化和灵活性 |
| 直接调用 API | 模块封装 | 职责分离，易扩展 |
