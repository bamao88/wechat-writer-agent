wechat-writer-agent/

│   ├── test_cli.py             # CLI 测试（待添加）

### 架构差异说明

| 规划 | 实际实现 | 差异原因 |
|------|---------|---------|
| Agent + 代码编排 | 模块化 Python | 更易测试和维护 |
| Agent 主动检索 | 预先检索 + Agent 可追加 | 兼顾结构化和灵活性 |
| 直接调用 API | 模块封装 | 职责分离，易扩展 |

**⚠️ 重要说明：API 接口兼容性**
- **标准实现**：使用 Anthropic SDK 调用 Claude API（`src/modules/generator.py`）
- **实际测试**：使用 OpenAI 兼容接口调用 Claude 模型（`generate_with_logs_openai.py`）
- **差异原因**：当前可用的 API Key 为第三方代理，通过 OpenAI 格式调用 Claude
- **影响范围**：
  - OpenAI 接口不支持 Anthropic 的 tool calling（无法追加检索）
  - 需要使用不同的 SDK 和参数格式
  - 核心生成逻辑和提示词相同
- **建议**：生产环境使用官方 Anthropic API 以获得完整功能支持
